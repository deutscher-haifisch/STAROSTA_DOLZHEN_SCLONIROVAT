# Учебная платформа «Лекторий»

Лабораторная работа по React: сайт учебной платформы, которая проводит онлайн и оффлайн занятия для физических и юридических лиц. Сделан по макету, без сторонних библиотек (только `react` и `react-dom`).

Страницы: Главная (с блоками «О нас» и «Контакты»), Партнеры, Лекторы, страница лектора с дисциплинами и тарифами. Данные преподавателей лежат в `src/data/lecturers.js`, задание и макет в `docs/`.

## Запуск

```
npm install
npm run dev
```

Сборка: `npm run build`.

Если страница не открывается по `localhost` (мешает VPN), запустите `npm run dev -- --host` и откройте адрес из строки Network.
